# История версий

## 0.2.0 — 2026-11-01

* ChatGPT Desktop (Codex): настоящий коннектор вместо заглушки на фикстурах. Лимиты 5ч и недели, время задач, модель и режим читаются из локальных логов приложения; проверено на живых логах. Устаревшие окна показываются пустыми.
* Меню в трее стало короче: убраны проверка связи, вход через Claude Desktop, другой способ входа, шаг 0 и папка данных. Они остались во вкладке «Настройки» дашборда (добавлена кнопка «Открыть папку данных»).

## 0.1.1 — 2026-11-01

* Восстановление связи: после временного сбоя опрос повторяется через 5, 10, 20 и 30 секунд, при пробуждении компьютера соединения сбрасываются и данные обновляются сразу,
  при возвращении сети опрос идёт без ожидания таймера.
* Кнопка «↻» в виджете и пункт трея «Обновить сейчас»; в сообщении об ошибке видно, когда будет следующая попытка.
* Исправлено: если время сброса недели уже прошло, а свежих данных нет, виджет больше не показывает расход прошлой недели как перерасход новой.

## 0.1.0 — 2026-10-31

Первая публичная версия.

* Плавающий виджет Windows: компактная строка и карточка, «доступно сейчас», недельная цель, режимы «Работа» и «Отпуск».
* Ядро расчёта (расписание UTC+3, цель T(t), коэффициент k, «доступно сейчас», пиковые часы) в отдельном пакете без Electron.
* Провайдер Claude: опрос `/api/organizations/{org}/usage` изнутри страницы claude.ai; проверен на тарифе Pro, значения совпали со страницей Usage.
* Вход в Claude: окно внутри приложения (в том числе через Google) и сессия из Claude Desktop одной кнопкой.
* Прокси: ключ запуска, переменная окружения, настройки (SOCKS5/HTTP); одна сессия и прокси для всех окон claude.ai.
* Дашборд, статистика по периодам, тепловая карта, детектор изменений лимитов, звуки и уведомления.
* Командная строка: статус, статистика, экспорт, реплей, поиск пропусков.
* Спайк источников данных (шаг 0) и задел под Codex на обезличенных фикстурах.
* Установщик Windows (NSIS), не подписан.
