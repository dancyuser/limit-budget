# Установка

Виджет работает на Windows 10 и 11 (x64); проверялся на Windows 11. Есть два способа: готовый установщик или сборка из исходников.

## Способ 1. Готовый установщик

1. Откройте раздел [Releases](https://github.com/dancyuser/limit-budget/releases/latest) и скачайте `LimitBudget-Setup-0.1.0.exe`.
2. Запустите файл. Установщик **не подписан**, поэтому Windows SmartScreen покажет «Windows защитила ваш компьютер»: нажмите «Подробнее» → «Выполнить в любом случае».
   Хотите убедиться, что файл не повреждён и совпадает с выложенным, сверьте контрольную сумму из описания релиза:

   ```powershell
   Get-FileHash .\LimitBudget-Setup-0.1.0.exe -Algorithm SHA256
   ```

3. Выберите папку установки (права администратора не нужны, установка идёт в профиль пользователя). В меню «Пуск» появится ярлык «Виджет лимитов».
4. Запустите программу: виджет появится на экране, а значок — в трее. При первом запуске откроется окно «Вход в Claude» (см. ниже).

**Обновление:** запустите новый установщик поверх старого. Настройки, база и сессия Claude сохраняются: они лежат в `%APPDATA%\LimitBudget`, а не в папке программы.
Перед установкой закройте виджет (правой кнопкой на значок в трее → «Выход»): приложение допускает только один экземпляр.

**Удаление:** «Параметры» → «Приложения» → «LimitBudget» → «Удалить». Данные в `%APPDATA%\LimitBudget` при этом остаются; удалите папку вручную, если они не нужны.

## Способ 2. Из исходников

Понадобятся:

* Windows 10/11;
* [Node.js](https://nodejs.org) 22.13 или новее (проверялось на 22.14; нужен встроенный `node:sqlite`);
* [Git](https://git-scm.com).

```bash
git clone https://github.com/dancyuser/limit-budget.git
cd limit-budget
npm install
npm test           # 162 теста; нужны только для проверки
npm run demo       # окно виджета на симулированных данных, без входа в Claude
npm start          # настоящий запуск: сборка и открытие виджета
```

Если запускаете из PowerShell и нужны ключи запуска (например, прокси), `npm start -- --proxy 10808` не сработает: PowerShell проглатывает `--`. Используйте

```bash
node scripts/start.mjs --proxy 10808
```

Собрать установщик самостоятельно:

```bash
npm run dist       # файл появится в release/
```

Путь к папке проекта должен быть короче примерно 120 символов: это ограничение `makensis`. Если путь длиннее, подключите проект как короткий диск и соберите оттуда:

```powershell
subst W: C:\очень\длинный\путь\к\limit-budget
npm run build                   # в обычной папке проекта
cd W:\packages\app; npm run dist
subst W: /d
```

## Первый вход в Claude

При первом запуске откроется окно «Вход в Claude».

1. **«Открыть окно входа»** открывает claude.ai внутри приложения. Войдите как обычно, в том числе через Google. Окно закроется само, как только появится сессия, ничего копировать не нужно.
2. **«Через Claude Desktop»**: если Claude Desktop установлен и вы в нём вошли, виджет возьмёт его сессию claude.ai и сразу проверит её запросом к сайту. Читаются только cookie claude.ai
   из хранилища Claude Desktop; действие запускается вашей кнопкой. Фоновая попытка раз в 6 часов выключена по умолчанию: «Настройки» → «Провайдеры и вход» → «Сессия Claude Desktop».
3. Если сайт не пускает (например, Cloudflare просит проверку), раскройте блок «Не получилось? Другой способ» и откройте claude.ai отдельным окном приложения.

Не нажимайте «Выйти» на claude.ai: сессия закроется на сервере, и вход понадобится снова. Сессия хранится только в профиле виджета и продлевается опросом.

## Если claude.ai недоступен без прокси

Укажите прокси в программе: значок в трее → «Настроить прокси (порт)…» → режим «Свой прокси», тип (например, SOCKS5), адрес и порт → «Применить и проверить».
Проверка покажет, дошёл ли запрос до claude.ai и до Google, и какой путь выбрало каждое окно. Подробности и ключи запуска — в [USAGE.md](USAGE.md#прокси).

## Где лежат данные

| Что | Где |
| --- | --- |
| Настройки, расписание, база | `%APPDATA%\LimitBudget\usage.sqlite` |
| Сессия claude.ai (профиль встроенного браузера) | `%APPDATA%\LimitBudget` (подпапки профиля Electron) |
| Отчёты шага 0 | `%APPDATA%\LimitBudget\spike` |
| Демо-режим | `%APPDATA%\LimitBudget-demo` (отдельно, с боевыми данными не пересекается) |

Открыть папку данных можно из трея: «Открыть папку данных».

## Частые проблемы

| Симптом | Что делать |
| --- | --- |
| SmartScreen не даёт запустить установщик | «Подробнее» → «Выполнить в любом случае»; файл не подписан сертификатом |
| Программа не открывается | Скорее всего, она уже запущена и находится в трее (допустим один экземпляр) |
| В виджете «нет связи с claude.ai» | Проверьте интернет и прокси: «Настроить прокси» в виджете или в трее |
| Google показывает ошибку при входе | Попробуйте позже (Google может ограничивать адрес выхода прокси) или используйте «Через Claude Desktop» |
| Cloudflare просит проверку | «Не получилось? Другой способ» → открыть claude.ai отдельным окном приложения, пройти проверку |
| `--proxy` не действует в PowerShell | Запускайте через `node scripts/start.mjs --proxy …`, см. [USAGE.md](USAGE.md#прокси) |
| Проценты в виджете расходятся со страницей Usage | Сверьтесь с шагом 0 (трей → «Шаг 0») и откройте issue с обезличенным отчётом |
